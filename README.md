Task Manager

Учебное консольное приложение, которое имитирует обработку заказов на складе или в службе доставки.

Что реализовано:

- класс Order для хранения данных заказа
- аннотация @OrderType для поля с типом заказа
- аннотация @Validate для обязательных полей
- валидатор OrderValidator, который проверяет поля через reflection
- BlockingQueue на основе LinkedBlockingQueue для очереди заказов
- ConcurrentHashMap для хранения обработанных заказов
- Producer, который создает заказы и кладет их в очередь
- два Consumer, которые забирают заказы из очереди и обрабатывают их
- ExecutorService для управления потоками
- вывод в консоль информации о создании и обработке заказов
- unit-тесты на JUnit 5
- JaCoCo для отчета о покрытии тестами
